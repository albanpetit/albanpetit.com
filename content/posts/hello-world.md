After a few years running this blog on Hugo with a custom theme, I've decided to migrate to a React-based stack using [Gatsby](https://www.gatsbyjs.com/) and [shadcn/ui](https://ui.shadcn.com/).

## Why the change?

Hugo is great — blazing fast builds, simple templating. But as I spend more and more time in the React ecosystem at work and in personal projects, I wanted a blog that lets me embed interactive components directly in posts, experiment with UI patterns, and feel at home in the codebase.

## The new stack

- **Gatsby 5** — static site generator with React
- **shadcn/ui** — beautifully designed components built on Radix UI + Tailwind
- **Tailwind CSS** — utility-first styling
- **TypeScript** — type safety everywhere
- **Markdown** — posts written in plain Markdown, processed by `gatsby-transformer-remark`

## What stays the same

All the content from the original blog will be migrated. The topics remain the same: electronics, web development, maker projects, and tutorials.

Stay tuned!
